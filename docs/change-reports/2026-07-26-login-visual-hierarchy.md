# 登录页视觉层级调整

日期：2026-07-26  
分支：`test`

## 目标

优化登录页左侧品牌区的视觉顺序，让核心的 AI 面试动效成为页面中段的视觉焦点，并将能力说明放入底部信息区。

## 调整内容

- 左侧信息区改为四段式网格：品牌、标题说明、居中动效、底部能力说明。
- `login-ai-stage` 置于中段并限定最大宽度，避免动效与说明卡片争夺横向空间。
- “智能追问、评测报告、断点续练”改为底部三列卡片，统一图标、标题和说明的节奏。
- 缩短动效区域高度，保证常见笔记本视口内的信息完整呈现。
- 保留原有鼠标微动、卡片 hover/tap 与减少动态效果偏好支持。
