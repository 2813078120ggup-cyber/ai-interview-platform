# 批量创建面试功能同步报告

## 变更时间

2026-07-25

## 问题

管理后台已将“批量创建”入口合并到“创建 AI 面试”弹框，但批量创建模式仍沿用旧版简化逻辑，只能选择模板、候选人、题库和排期间隔。

这导致批量创建没有同步单个创建中的完整能力。

## 为什么是问题

单个创建和批量创建属于同一个“创建 AI 面试”业务流程。两者能力不一致会造成：

- 管理员以为批量创建也支持 AI 面试官风格，但实际固定为默认风格。
- 批量创建只能题库抽题，不能自定义选择题目。
- 批量创建不能单独调整面试主题、面试类型、题数和时长。
- 同一个创建弹框中两种模式体验不一致，容易产生误解。

## 本次修改

- 扩展批量创建状态结构，使其支持：
  - 批量面试主题
  - AI 面试官风格
  - 面试类型
  - 面试时长
  - 自定义选择任意题目
  - 选择题库抽题
  - 抽题数量
  - 第一场开始时间
  - 场次间隔
  - 多候选人选择
- 批量创建模板点击后会同步：
  - 面试标题
  - 面试类型
  - 面试时长
  - 默认题数
  - 题目来源
- 批量创建提交时不再固定 `big-tech` 面试官风格，而是按用户选择提交。
- 批量创建提交时不再强制题库抽题，可使用自定义题目。
- 优化批量创建区块说明，让管理员明确“批量创建与单个创建共用配置能力”。

## 影响范围

- 前端页面：
  - `frontend-react/src/pages/admin-interviews.tsx`

