# 2026-07-25 管理员面试通知与发送模板

## 本次目标

将顶部通知按钮从“仅展示图标”升级为可用功能：管理员可以针对具体面试向候选人发送通知，并在发送时创建、复用通知模板。

## 修改内容

1. 新增通知数据工具
   - 新增 `frontend-react/src/lib/notifications.ts`
   - 支持通知列表、模板列表、发送通知、标记已读、全部已读、模板变量替换。
   - 默认内置“面试开始提醒”“练习跟进提醒”两个模板。

2. 新增统一通知中心
   - 新增 `frontend-react/src/components/notification-center.tsx`
   - 管理员端顶部铃铛展示最近发送记录。
   - 候选人端顶部铃铛展示收到的通知、未读数量，并支持全部已读。

3. 面试管理增加发送通知入口
   - 在管理员面试管理表格操作列新增“通知”按钮。
   - 点击后打开发送弹窗，自动带入当前面试、候选人和预约时间。
   - 支持选择模板、编辑标题/内容、保存当前内容为新模板。

4. 操作留痕
   - 管理员发送通知后写入前端操作日志，便于后续排查和演示。

## 当前实现边界

通知和模板当前使用浏览器 `localStorage` 保存，适合本地演示和前端交互验证。若要支持云端多用户、多设备同步，下一步应补充后端数据库表和接口：

- `notification`
- `notification_template`
- 通知发送接口
- 候选人通知查询接口
- 已读状态接口
