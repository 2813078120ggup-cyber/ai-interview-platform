# 2026-07-25 题库启用与可见范围控制优化报告

## 背景

题库卡片上已经展示「已启用」和「练习可见」等状态，但之前只是静态信息。用户希望这些状态可以直接调节，并让可见范围设置真正可用。

## 本次改动

1. 在题库卡片右上角增加启用/停用操作按钮。
   - 已启用状态显示为轻量胶囊开关。
   - 点击后调用真实接口更新题库状态。
   - 停用后提示该题库不可用于新面试。

2. 在题库卡片中增加「可见范围」设置区。
   - 支持「仅管理端」「内部可见」「练习可见」三种范围。
   - 下拉选择后立即调用真实接口保存。
   - 卡片内同步展示范围说明，降低误操作风险。

3. 新建题库弹窗补充启用状态设置。
   - 可以选择创建后立即启用。
   - 也可以先保存为停用。

4. 搜索区增加可见范围筛选。
   - 管理员可以快速查看练习可见、内部可见或仅管理端题库。

5. 修复题库管理页源码中文乱码问题。
   - 将页面文案恢复为正常 UTF-8 中文。
   - 保留 CSV/TSV 批量导入能力。
   - 下载模板增加 UTF-8 BOM，减少 Excel 打开中文乱码概率。

6. 增加操作日志记录。
   - 启用题库
   - 停用题库
   - 调整可见范围
   - 创建题库
   - 批量导入题目

## 接口实现方式

本次复用现有后端真实接口：

- `PUT /v1/question-banks/{id}`

没有新增数据库字段，也没有新增后端接口。

- Vite 生产构建通过

## 影响范围

本次主要影响管理后台题库管理页。候选人端练习题库仍由后端根据 `status = 1` 且 `visibility = 2` 控制，因此后台调整后会影响候选人可见的练习题库范围。
