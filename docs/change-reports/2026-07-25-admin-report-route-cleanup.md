# 2026-07-25 管理端冗余报告页清理

## 本次目标

清理管理端中已经不再符合当前产品结构的冗余内容，让“评测报告”统一收敛到“面试管理”页面中。

## 已清理内容

- 删除旧的独立管理端报告页 `AdminReports`。
- 移除 `/admin/reports` 前端路由和对应导入。
- 工作台中的“查看评测报告”入口改为“进入面试管理”。
- 候选人详情页的报告列表改为跳转到 `/admin/interviews?reportInterviewId=...`。
- 面试回顾页的“查看评测报告”改为跳转到面试管理并自动打开报告弹层。
- 面试管理页新增 `reportInterviewId` 查询参数支持，用于自动打开指定面试报告。

## 为什么这样处理

此前评测报告已经被合并到面试管理的操作菜单中，继续保留旧报告中心会造成：

- 两套报告查看路径并存，用户认知重复。
- 老页面样式和新管理后台设计语言不一致。
- 后续维护 PDF、训练计划、报告弹层时容易出现两套实现不一致。

## 验证

- 前端：`npm run build` 通过。
- 后端：`mvn -q -DskipTests package` 通过。

## 备注

- 本次只清理确认冗余的管理端旧报告页，不影响候选人端报告页。
- 本地 `backend/src/main/resources/application.yml` 配置变更未纳入提交。
