# 2026-07-25 变更报告：暗色模式登录页与管理入口可读性修复

## 背景

用户在暗色模式下退出登录后，登录页仍继承全局暗色主题变量，导致浅色登录界面中的标题、表单文字和说明内容出现低对比度问题。同时，管理端工作台右侧“管理面试”按钮在暗色模式下出现浅色按钮配白色文字，影响可读性。

## 本次修改

1. 登录页增加独立浅色主题作用域。
   - `login-page-shell` 固定使用浅色设计变量。
   - 登录页输入框、标题、标签、占位符统一按浅色模式渲染。
   - 避免退出登录后继续继承 `html.dark` 的暗色变量。

2. 管理端工作台“管理面试”按钮修复暗色可读性。
   - 按钮文字改为使用 `primary-foreground`。
   - 暗色模式下显式设置为浅色按钮 + 深色文字。
   - hover 状态保持高对比度。

## 影响范围

- `frontend-react/src/pages/login.tsx`
- `frontend-react/src/pages/admin-workspace.tsx`
- `frontend-react/src/styles.css`

## 验证

- 已执行 `npm run build`
- TypeScript 编译通过
- Vite 生产构建通过

## 备注

登录页作为品牌入口页，当前固定按浅色视觉展示；后台和候选人工作区仍继续支持深色/浅色切换。
