# AI 面试问答助手

## 本次变更

- 增加已登录候选人可用的全局悬浮式 AI 面试问答助手。
- 新增受认证保护的接口：POST /v1/ai-assistant/chat。
- 复用现有 DeepSeek 网关与密钥配置，不接入 OpenAI。
- 增加面试教练系统提示词：帮助候选人理解题目、组织回答、发现知识盲点和模拟追问；拒绝代写、作弊及规避真实考核的请求。

## 交互与约束

- 助手在候选人端所有受保护页面可随时打开，管理员端不展示。
- 单次请求保留最近最多 12 条消息；单条消息最长 2000 个字符。
- 角色字段只允许 user 或 assistant。
- AI 输出被提示词限制为 300 个中文字符以内，便于快速阅读和继续交流。

## 验证

- 后端：D:\apache-maven-3.9.12\bin\mvn.cmd -q -DskipTests compile
- 前端：D:\nodejs\npm.cmd run build

## 部署影响

此功能同时变更前端与后端。云服务器更新时需要重新导入并重建 backend、frontend 两个镜像；仅更新前端无法调用新增接口。
