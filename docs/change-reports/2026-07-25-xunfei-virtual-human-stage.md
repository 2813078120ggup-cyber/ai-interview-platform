# 2026-07-25 面试间讯飞虚拟人舞台优化报告

## 本次目标

将面试房间右侧原“语音朗读”区域升级为虚拟人展示区域，让讯飞虚拟人直接出现在候选人面试界面的固定卡片中。

## 修改内容

1. 右侧栏宽度从 `310px` 调整为 `360px`，给虚拟人画面留出更完整展示空间。
2. 原顶部小画面改为 `360px` 高的虚拟人舞台。
3. 支持三类虚拟人返回结果：
   - `mp4 / webm / ogg`：直接使用 `video` 播放。
   - `http/https` 可嵌入页面：使用 `iframe` 承载。
   - 浏览器不支持的流地址，例如 RTMP / HLS 未转码场景：在舞台中展示明确提示，避免空白。
4. 舞台下方保留朗读控制：
   - 已接入讯飞时显示“让虚拟人重读本题”。
   - 未接入或降级时显示“重新朗读本题”。
5. 增加虚拟人连接状态：
   - 连接中
   - 讯飞虚拟人已接入
   - 本地数字人兜底

## 验证结果

- 前端 `npm run build` 通过。

## 备注

如果讯飞控制台返回的是 RTMP 地址，浏览器不能直接播放，需要后续增加 RTMP → HLS / WebRTC 转换，或使用讯飞提供的可嵌入播放页 / Web SDK。
