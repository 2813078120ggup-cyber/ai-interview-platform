# 2026-07-25 新增面试通过通知模板

## 问题

管理员发送通知时，默认模板里缺少“面试通过”场景，只能手动输入通过通知内容。

## 为什么是问题

面试通过是评测平台高频通知场景。如果每次都手动编写，容易出现文案不统一、遗漏报告提醒或后续安排提示的问题。

## 如何修改

在 `frontend-react/src/lib/notifications.ts` 的默认通知模板中新增：

- 模板名称：面试通过通知
- 标题：恭喜你通过本次 AI 面试评测
- 内容：自动带入候选人姓名和面试标题，提醒候选人查看评测报告、复盘优势与改进建议，并留意后续安排。

同时修复默认模板文案中的中文乱码，确保管理员下拉选择时显示正常。

## 修改文件

- `frontend-react/src/lib/notifications.ts`

## 验证

已执行：

```bash
npm run build
```

结果：构建通过。Vite 仍提示主 chunk 超过 500KB，这是既有拆包优化项，不影响本次模板更新。
