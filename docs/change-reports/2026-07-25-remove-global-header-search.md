# 2026-07-25 顶部无效全局搜索框移除报告

## ① 问题

管理员端和候选人端顶部导航区域存在一个全局搜索框，但该搜索框没有绑定实际业务逻辑，输入后不会触发有效搜索。

## ② 为什么是问题

- 用户会误以为可以跨候选人、面试、题库和报告进行全局检索。
- 无效输入框会降低界面可信度。
- 当前页面内部已经有真实可用的列表搜索和筛选，顶部全局搜索会造成重复和干扰。

## ③ 如何修改

- 移除管理员端顶部全局搜索框。
- 移除候选人端顶部全局搜索框。
- 保留右侧暗色模式、通知、退出账号和头像操作区。
- 保留各业务页面内部已经接入逻辑的搜索筛选功能。

## ④ 验证结果

- 已执行 `npm run build`。
- TypeScript 编译通过。
- Vite 生产构建通过。
- 构建仅存在 chunk size 提示，不影响运行。

## ⑤ 影响范围

- 影响文件：
  - `frontend-react/src/components/admin-page-shell.tsx`
  - `frontend-react/src/components/candidate-page-shell.tsx`
- 不影响后端接口。
- 不影响业务页面内部搜索、筛选、分页和操作按钮。
