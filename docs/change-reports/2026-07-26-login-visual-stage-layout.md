# 登录页动态舞台与功能卡片布局优化

日期：2026-07-26
分支：`test`

## 调整内容

- 扩展登录页左侧动态舞台的可用高度，并将轨道、核心图标和波形整体下移至视觉中心。
- 取消舞台内部裁切，使轨道动画、环绕图标与波形不会被容器边缘遮住。
- 将三个能力说明卡片由纵向大卡片压缩为紧凑横向卡片：图标在左，标题一行，描述一行。
- 精简说明文案，确保桌面端无需换行；窄尺寸下使用省略，避免撑破布局。
- 将“断点续练”说明进一步收敛为“自动保存草稿”，避免第三张卡片在常见桌面宽度下发生文字截断。

## 验证

- 前端 TypeScript 校验与 Vite 生产构建通过。
