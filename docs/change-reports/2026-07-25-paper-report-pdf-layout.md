# 2026-07-25 纸质版 PDF 报告样式调整报告

## 本次目标

重新设计“查看报告 / 导出 PDF”的打印版样式，让 PDF 更像正式纸质评测报告，而不是网页报告界面的截图。

## 修改内容

1. 新增打印专用纸质报告模板：
   - 网页浏览仍使用原来的现代卡片报告界面。
   - 导出 PDF / 打印时自动切换为纸质报告版。

2. 纸质版报告结构：
   - 报告页眉：平台名称、报告标题、报告编号等信息。
   - 综合得分：右侧圆形分数摘要。
   - 综合结论：根据总分显示“优秀 / 良好 / 达标 / 待加强 / 需重点提升”。
   - 能力评分表：四维能力、得分、等级、说明。
   - 能力画像：四维能力横向进度条。
   - 评测结论：优势表现、待提升项、行动建议。
   - 页脚：平台说明与报告用途说明。

3. 打印样式优化：
   - 固定使用亮色纸质风格，不受系统暗色模式影响。
   - 使用 A4 纸张适配排版。
   - 减少网页圆角、阴影和大面积色块。
   - 使用更适合打印的字号、边距、表格和分隔线。

## 影响范围

- `frontend-react/src/components/report-detail-view.tsx`
- `frontend-react/src/styles.css`

## 编译验证

- 前端：`npm run build` 通过。

## 后续建议

如果后续要进一步提升交付质量，可以改成后端生成 PDF 文件并提供下载接口，这样能完全避免浏览器打印差异。
