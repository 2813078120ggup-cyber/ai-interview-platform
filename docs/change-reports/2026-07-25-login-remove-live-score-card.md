# 2026-07-25 登录页多余装饰卡片移除报告

## ① 问题

登录页左侧视觉区域多出一个 `LIVE SCORE` 能力评分装饰卡片，位置过于突兀，和当前登录页的留白、主标题、产品说明层级不协调。

## ② 为什么是问题

- 登录页是用户第一入口，视觉应尽量聚焦在品牌识别和登录操作上。
- 该卡片不承载真实交互信息，容易被误认为功能模块。
- 当前页面已经有主视觉标题、产品说明和登录表单，额外浮层会增加视觉噪音。

## ③ 如何修改

- 删除登录页左侧 `LIVE SCORE` 装饰卡片。
- 保留登录页主标题、平台说明和核心卖点展示。
- 不修改登录接口、角色跳转、认证逻辑和路由逻辑。

## ④ 验证结果

- 已执行 `npm run build`。
- TypeScript 编译通过。
- Vite 生产构建通过。
- 构建仅存在 chunk size 提示，不影响运行。

## ⑤ 影响范围

- 仅影响 React 前端登录页视觉展示。
- 不影响后端接口。
- 不影响候选人端、管理员端已有业务功能。
