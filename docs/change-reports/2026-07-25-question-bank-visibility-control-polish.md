# 题库可见范围控件美化报告

## 本次目标

优化管理后台题库卡片中的“可见范围”设置区域，让它从普通下拉框升级为更直观、更符合当前后台风格的配置控件。

## 修改内容

1. 可见范围控件重构
   - 将原有单一下拉框改为三段式可点击范围卡。
   - 当前选中的可见范围使用边框、高亮背景和阴影强调。
   - 未选中项支持 hover 上浮和高亮反馈。

2. 视觉层级优化
   - 外层容器改为轻量渐变面板，弱化生硬表单感。
   - 保留“可见范围”标题与当前说明，降低用户理解成本。
   - 选项内展示图标、名称和说明，比原下拉框更清楚。

3. 功能逻辑保留
   - 点击任一范围选项仍会调用原有 `updateBank` 更新接口。
   - 更新中和当前已选项会禁用，避免重复提交。
   - 审计日志、状态刷新等逻辑不变。

## 涉及文件

- `frontend-react/src/pages/admin-question-banks.tsx`
