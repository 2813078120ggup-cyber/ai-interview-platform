# OpenTalking 选择题提交反馈流程优化

日期：2026-07-26
范围：`frontend-react/src/pages/interview-room.tsx`

## 调整内容

- 选择题提交后改为题库本地确定性判定，不调用 DeepSeek，也不调用 OpenTalking 的智能问答链路。
- 回答正确时，AI 面试官固定反馈：`回答正确，让我们来继续下一道题。`
- 回答错误时，AI 面试官固定反馈正确答案和题库解析，再进入下一题。
- AI 面试官的反馈会追加到当前对话记录，而不是覆盖候选人刚提交的回答；虚拟人播报文本与对话框文本保持一致。
- 标准答案兼容题库中常见的 `A`、`A,C`、`["A","C"]` 三种格式，避免原始文本答案被解析为空而导致误判。

## 交互流程

1. 候选人选择答案并提交。
2. 前端保存选择结果。
3. 本地比对题库标准答案，生成唯一的正确或错误讲评。
4. 讲评同时写入对话框并交由已启动的虚拟人文本播报。
5. 播报完成后自动切换到下一道题；最后一题保留在当前题目以便结束面试。

## 验证

执行：`npm.cmd run build`
结果：通过（TypeScript 编译和 Vite 生产构建成功）。

## 说明

本变更遵循虚拟人 Web SDK 的文本驱动生命周期：选择题只播报确定性讲评，避免将选择题答案再交给 AI 产生追问或不一致的回复。
