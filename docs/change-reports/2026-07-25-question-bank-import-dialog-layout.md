# 题库批量导入弹窗布局优化

日期：2026-07-25  
分支：test

## 问题

管理后台“题库批量导入”弹窗中，右侧“导入预览”区域会被表格最小宽度撑开，导致预览卡片溢出弹窗主体。

## 修改内容

1. 弹窗容器改为响应式宽度
   - 使用视口安全宽度，避免在不同屏幕尺寸下超出窗口。
   - 弹窗主体增加 `overflow-hidden`，防止内部卡片穿出圆角容器。

2. 导入区域网格改为可收缩布局
   - 右侧预览列改为 `minmax(0, 1fr)`。
   - 左右两栏均增加 `min-w-0`，允许内容在网格中正确收缩。

3. 预览表格限制在卡片内部滚动
   - 预览卡片增加 `overflow-hidden`。
   - 表格容器增加横向滚动。
   - 表格最小宽度从 760px 调整为 680px，减少不必要的横向压力。

4. 预览头部适配窄屏
   - “提交导入”按钮在小屏下独占一行，避免挤压标题区。

## 验证

- `npm run build` 通过。

## 影响范围

- 仅影响管理后台题库批量导入弹窗前端布局。
- 不改动导入解析逻辑和后端接口。
