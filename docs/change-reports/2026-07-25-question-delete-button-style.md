# 2026-07-25 题目删除按钮样式统一报告

## 背景

用户反馈题目维护列表中「删除」按钮是纯文字样式，与旁边「修改」按钮的边框胶囊风格不统一。

## 本次改动

1. 将「删除」按钮从 ghost 文本态改为 secondary 边框胶囊按钮。
2. 保持与「修改」按钮一致的尺寸、圆角、边框和图标间距。
3. 使用浅红色背景、红色边框和红色文字表达危险操作。
4. 补充深色模式下的删除按钮颜色，避免暗色主题里对比异常。

## 验证结果

- 已执行 `npm run build`
- TypeScript 编译通过
- Vite 生产构建通过
- 构建仅保留 chunk 体积提示，不影响运行

## 影响范围

本次只调整管理后台题目维护列表中的删除按钮样式，不修改删除业务逻辑。
