# 2026-07-25 候选人能力报告图表优化报告

## 变更目标

优化候选人端“能力报告”页面中的历史综合能力变化图与四维能力画像图，使其符合当前暖白、黑色、暖棕、紫粉的整体视觉体系，并修复雷达图展示不完整的问题。

## 主要变更

1. 历史综合能力变化图
   - 移除旧青绿色折线与填充色。
   - 改为更简洁克制的暖棕色折线。
   - 面积填充改为低透明度暖棕渐变，整体更轻、更大气。
   - 折线节点缩小，降低装饰感，突出数据本身。

2. 四维能力画像图
   - 右侧图表区域加宽。
   - 雷达图 SVG 从 `300x300` 调整为 `360x330`。
   - 放大雷达图容器，并增加内边距。
   - 左右标签增加安全边距，避免“表达能力”“应变能力”等标签被裁切。
   - 雷达图颜色改为暖棕填充、紫色节点，与全局品牌色保持一致。

## 验证结果

- 已执行 `npm run build`。
- TypeScript 编译通过。
- Vite 生产构建通过。
- 已检查能力报告页不再残留旧青绿色 `#14b8a6`、`#0f766e`。

## 后续建议

- 如果后续需要更强的数据展示能力，可引入统一 Chart 组件，将趋势图、雷达图、报告 PDF 中的图表样式抽象成可复用图表系统。
