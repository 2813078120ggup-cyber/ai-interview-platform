# 管理端面试操作区单页展示优化

## 调整时间

2026-07-25

## 背景

管理后台「面试管理」列表的操作按钮较多，之前通过增加表格宽度缓解拥挤，但会导致页面需要横向拖动，不符合当前页面一屏查看的使用预期。

## 本次修改

- 移除面试列表横向滚动容器，表格改为固定布局并占满当前内容区。
- 通过 `colgroup` 为面试主题、候选人、时间、状态、报告和操作列分配比例宽度。
- 操作区改为更紧凑的固定五列按钮：
  - 通知
  - 回顾
  - 通过
  - 删除
  - 查看报告
- 在普通宽度下隐藏按钮图标，只保留文字，避免按钮撑开表格。
- 在超宽屏下保留图标，增强识别度。
- 保留原有操作顺序和同列对齐规则。
