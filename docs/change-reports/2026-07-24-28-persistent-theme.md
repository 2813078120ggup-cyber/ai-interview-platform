# 全局深色模式持久化

## 问题

深色模式状态原本只保存在工作概览页面组件内。切换到使用另一套页面壳的能力报告等路由，或刷新页面后，主题没有统一的初始化来源，容易恢复为浅色模式。

## 修复

- 新增全局主题工具，统一读取和写入浏览器本地存储。
- 在应用启动前同步 html 根节点的 dark class，避免路由切换或刷新产生主题闪烁。
- 工作概览的主题按钮改为使用全局主题状态。

## 结果

- 在任意页面切换深色或浅色模式后，后续跨页面导航与刷新都会保持选择。
- 所有使用 Tailwind dark 变体和全局颜色令牌的界面都会同步生效。

## 验证

- 前端生产构建：D:\nodejs\npm.cmd run build
