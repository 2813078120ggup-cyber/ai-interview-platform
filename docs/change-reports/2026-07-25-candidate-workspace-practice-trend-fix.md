# 2026-07-25 候选人工作概览模拟面试与能力趋势修复报告

## 背景

候选人工作概览页面存在两个体验问题：

1. 「开始模拟面试」按钮点击后没有反应。
2. 右侧「能力趋势」区域没有正确展示图形。

## 问题原因

1. 工作概览页此前使用静态展示内容，按钮没有绑定真实点击事件。
2. 能力趋势此前是硬编码的静态柱状展示，未接入候选人的真实报告摘要数据。
3. `app.tsx` 中候选人工作概览文案存在历史中文乱码，影响后续维护。

## 本次改动

1. 修复「开始模拟面试」按钮。
   - 页面加载时请求候选人可练习题库。
   - 点击按钮后调用真实接口创建模拟面试。
   - 创建成功后自动进入对应面试房间。
   - 如果当前没有可练习题库，则跳转到题库与岗位页面。

2. 修复右侧能力趋势图。
   - 接入 `GET /v1/reports/my/summary`。
   - 使用最近 6 次报告绘制折线趋势。
   - 展示得分点、趋势折线、淡色面积层和坐标辅助线。
   - 没有报告时显示明确空状态说明。

3. 工作概览统计卡片改为真实数据驱动。
   - 本周练习
   - 平均能力分
   - 待完成面试
   - AI 反馈

4. 修复 `app.tsx` 候选人工作概览中文乱码。

## 接口使用

- `GET /v1/interviews`
- `GET /v1/interviews/practice/banks`
- `POST /v1/interviews/practice`
- `GET /v1/reports/my/summary`

## 验证结果

- 已执行 `npm run build`
- TypeScript 编译通过
- Vite 生产构建通过
- 构建仅保留 chunk 体积提示，不影响运行

## 影响范围

本次只影响候选人工作概览页面，不改变管理后台和面试房间业务逻辑。
