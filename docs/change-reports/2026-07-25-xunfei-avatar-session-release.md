# 2026-07-25 讯飞虚拟人 11203 会话释放修复

## 背景

讯飞虚拟人返回 `11203 / avatar authentication failed`。根据讯飞虚拟人接入规则，该错误常见于虚拟人授权、并发路数不足、订阅过期或历史会话未正常释放。

## 本次调整

- 后端新增 `POST /api/v1/virtual-human/stop`，用于主动释放讯飞虚拟人会话。
- 前端面试间在以下场景主动调用释放：
  - 离开面试间页面。
  - 结束面试。
  - React 组件卸载。
- 前端释放后会清空本地虚拟人会话状态，避免重复使用已失效 session。

## 预期效果

减少讯飞侧“持续中”残留会话，降低下一次启动虚拟人时触发 `11203 avatar authentication failed` 的概率。

## 仍需人工确认

如果释放逻辑上线后仍报 `11203`，需要在讯飞控制台确认：

- 当前接口服务的在线虚拟人驱动授权是否有效。
- 剩余交互时长是否大于 0。
- 并发路数是否被占满。
- 虚拟人形象 ID 是否属于同一个接口服务。
- 发音人/音色是否已授权。
- 控制台是否存在“持续中”的旧会话，需要手动停止或等待释放。
