# 2026-07-25 已结束面试报告查看逻辑调整报告

## 本次目标

调整报告查看权限的前端判断：只要面试已经结束并且报告存在，就允许查看报告，不再要求必须是“已出报告 / 已通过 / 未通过”状态。

## 修改内容

1. 更新统一状态工具 `canViewReport`：
   - `已结束`
   - `已出报告`
   - `已通过`
   - `未通过`

   以上状态均允许查看报告。

2. 影响管理端和候选端：
   - 管理后台“更多”菜单中的“查看报告”会按新逻辑显示。
   - 候选人面试大厅的“查看报告”按钮会按新逻辑显示。

## 注意

前端仍然会同时判断“报告是否真实存在”。如果面试已结束但后端还没有报告数据，界面不会展示“查看报告”入口。

- 前端：`npm run build` 通过。
