# 2026-07-25 题目维护编辑与删除功能报告

## 背景

用户反馈题库「维护题目」页面只能新增题目，不符合后台维护场景。题目管理需要支持新增、修改和删除完整闭环。

## 本次改动

1. 题目列表增加操作按钮。
   - 每道题目右侧增加「修改」按钮。
   - 每道题目右侧增加「删除」按钮。

2. 新增编辑题目能力。
   - 点击「修改」后打开编辑弹窗。
   - 自动回填当前题目的完整字段。
   - 保存后调用真实后端接口更新数据。

3. 新增删除题目能力。
   - 删除前弹出确认提示。
   - 确认后调用真实后端接口删除数据。
   - 删除成功后前端列表即时刷新。

4. 完善题目表单字段。
   - 题型
   - 难度
   - 题目内容
   - 选项 JSON
   - 标准答案 JSON
   - 参考答案 / 回答模板
   - 解析
   - 分值
   - 状态
   - 排序
   - 标签

5. 修复题目维护页中文乱码。
   - 页面标题、筛选项、按钮、空状态、错误提示全部恢复正常中文。

6. 增加操作日志记录。
   - 新增题目
   - 修改题目
   - 删除题目

## 接口实现方式

本次复用现有后端真实接口：

- `POST /v1/question-banks/{bankId}/questions`
- `PUT /v1/question-banks/{bankId}/questions/{id}`
- `DELETE /v1/question-banks/{bankId}/questions/{id}`

没有新增数据库字段，也没有新增后端接口。
