# 管理端创建面试入口合并报告

## 变更时间

2026-07-25

## 变更目标

将管理后台独立的“批量创建”入口合并到“创建 AI 面试”弹框中，减少页面顶部操作入口，让单个创建和批量创建统一在同一套创建流程里完成。

## 本次调整

- 删除面试管理页顶部独立的“批量创建”按钮，只保留“创建 AI 面试”。
- 在“创建 AI 面试”弹框内新增“单个创建 / 批量创建”双模式切换。
- 单个创建模式保留原有能力：
  - 面试模板快捷套用
  - 候选人下拉选择
  - AI 面试官风格选择
  - 自定义选择任意题目
  - 从题库随机抽题
  - 设置预约时间和面试时长
- 批量创建模式合并原有能力：
  - 选择面试模板
  - 选择面试题库
  - 多选候选人
  - 设置第一场开始时间
  - 设置场次间隔
  - 根据候选人顺序自动批量排期
- 优化弹框信息层级，让批量排期说明更清晰。

## 影响范围

- 前端页面：
  - `frontend-react/src/pages/admin-interviews.tsx`

## 验证结果

- 已执行前端生产构建：

```bash
npm run build
```

- 构建结果：通过。

## 备注

本次只调整管理后台前端交互入口和弹框组织方式，后端批量创建逻辑仍复用原有创建面试接口，不改变数据库结构。
