# 管理后台面试通过与删除操作

日期：2026-07-25  
分支：test

## 本次改动

1. 后端新增面试状态 `已通过`
   - 在 `Interview` 状态常量中新增 `PASSED = 4`。
   - 面试分页查询支持按 `已通过` 状态筛选。

2. 后端新增管理端操作接口
   - `POST /v1/interviews/{id}/pass`：管理员将面试标记为已通过。
   - `DELETE /v1/interviews/{id}`：管理员删除面试。
   - 删除操作复用数据库外键级联关系，清理该面试关联的题目快照、回答、评测任务与报告数据。

3. 管理后台面试管理操作列优化
   - 新增“通过”按钮。
   - 新增“删除”按钮。
   - 增加居中确认弹窗，避免误操作。
   - 调整操作按钮为固定列位：通知、回顾、通过、删除、查看报告，同类按钮在不同行中保持纵向对齐。
   - “查看报告”固定放在操作列最后，避免报告按钮穿插导致视觉跳动。

4. 状态展示同步
   - 管理端面试列表、管理员工作台、管理员回顾页、候选人详情页、候选人面试大厅、面试房间均识别 `已通过` 状态。
   - 已通过面试在候选人端按已结束处理，不再进入作答流程。

5. 操作日志增强
   - 补充清空日志能力。
   - 操作日志页增加统计、筛选、刷新、导出 CSV 和清空确认弹窗。
   - 通过面试、删除面试会记录到本地操作日志。

## 验证

- 后端：`mvn -B -ntp -DskipTests package` 通过。
- 前端：`npm run build` 通过。

## 注意事项

- 本次未提交 `backend/src/main/resources/application.yml`，该文件仍保留为本地运行配置。
- `已通过` 目前是业务标记状态，不会自动生成新的报告；若该面试已经生成报告，仍可在操作列查看报告。
