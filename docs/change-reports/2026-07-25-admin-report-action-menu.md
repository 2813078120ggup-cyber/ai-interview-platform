# 2026-07-25 管理端报告入口收纳调整报告

## 本次目标

优化管理后台“面试管理”列表的操作列，把“查看报告”从固定按钮移动到“更多”菜单中，减少表格横向拥挤。

## 修改内容

1. 操作列从三列调整为两列：
   - 保留“回顾”
   - 保留“更多”
   - 移除外层固定展示的“查看报告”按钮

2. “更多”菜单新增“查看报告”入口：
   - 仅当该面试已有报告且当前状态允许查看报告时显示
   - 点击后关闭菜单并打开原有报告弹窗

3. 下拉菜单宽度微调：
   - 从 `w-36` 调整为 `w-40`
   - 避免“标记通过 / 查看报告”等菜单项过于拥挤

## 影响范围

- `frontend-react/src/pages/admin-interviews.tsx`

## 编译验证

- 前端：`npm run build` 通过。

## 后续建议

后续可以继续把“通知 / 通过 / 删除 / 查看报告”按业务风险分组，例如普通操作、结果操作、危险操作三段式展示。
