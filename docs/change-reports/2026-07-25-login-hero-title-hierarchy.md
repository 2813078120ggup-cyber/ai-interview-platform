# 登录页 Hero 标题层级优化报告

## 本次目标

优化登录页左侧 Hero 大标题，使标题不再所有文字使用同一字号，增强视觉节奏和重点表达。

## 修改内容

1. 标题层级重构
   - 将标题拆为三层：
     - “每一次模拟面试，”
     - “都成为下一次的”
     - “底气。”
   - 前两层使用相对收敛的字号，最后关键词“底气”使用更大字号形成视觉重点。

2. 重点词视觉增强
   - 为“底气。”增加轻量阴影。
   - 增加柔和的底部强调线，提升记忆点但避免过度装饰。

3. 排版稳定性
   - 保持标题整体最大宽度不变。
   - 避免标题形成一整块压迫感过强的黑色文字区域。

## 涉及文件

- `frontend-react/src/pages/login.tsx`
- `frontend-react/src/styles.css`

npm run build
