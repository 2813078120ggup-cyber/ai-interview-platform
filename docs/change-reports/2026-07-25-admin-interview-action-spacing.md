# 管理端面试操作按钮间距优化

## 调整时间

2026-07-25

## 背景

管理后台「面试管理」列表中，操作按钮包含通知、回顾、通过、删除、查看报告。按钮数量较多时视觉上偏拥挤，影响快速识别和点击。

## 本次修改

- 扩大面试列表表格最小宽度，给操作区预留更稳定的横向空间。
- 将操作列设置为固定宽度，保持同类按钮在每一行同列对齐。
- 操作按钮继续按照「通知 / 回顾 / 通过 / 删除 / 查看报告」排列，其中查看报告保持最后。
- 调整按钮间距、字号、内边距和阴影，让按钮更轻、更舒展。
- 删除按钮保持红色危险语义，但降低视觉压迫感，避免操作区过于杂乱。
