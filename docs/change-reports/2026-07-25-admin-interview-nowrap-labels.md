# 管理端面试列表文字横向展示修复

## 调整时间

2026-07-25

## 背景

管理后台「面试管理」列表在压缩到单页展示后，部分短文本状态标签可能因为列宽较窄被挤成竖向显示，例如「进行中」逐字换行，影响阅读体验。

## 本次修改

- 为全局 `Badge` 组件增加 `whitespace-nowrap`，防止状态标签、报告标签被拆行。
- 调整面试管理列表列宽比例，为「状态」和「报告」列增加展示空间。
- 为操作按钮增加 `whitespace-nowrap`，确保「通知」「回顾」「通过」「删除」「查看报告」均横向展示。
- 保留单页展示逻辑，不恢复横向滚动。

## 验证结果

- 已执行 `npm run build`
- TypeScript 编译通过
- Vite 构建通过
- 当前仅存在 Vite chunk 体积提示，不影响运行

## 影响范围

- 管理端：面试管理列表
- 全局：Badge 标签组件的文字不再自动换行
- 不影响后端接口和数据库结构
