# 2026-07-25 报告 PDF 导出优化报告

## 变更目标

优化候选人端与管理端的报告导出体验，避免直接调用浏览器打印时把导航栏、遮罩、按钮、页面背景等非报告内容一起导出。

## 主要变更

1. 新增统一导出函数
   - 新增 `frontend-react/src/lib/report-export.ts`。
   - 导出前自动切换到报告打印模式。
   - 自动设置浏览器打印标题，便于保存 PDF 时生成更清晰的文件名。
   - 打印结束后恢复原始页面标题与样式状态。

2. 新增报告专用打印样式
   - 使用 A4 页面尺寸与 14mm 页面边距。
   - 打印时只显示带 `data-print-root` 的报告主体。
   - 隐藏侧边栏、顶部栏、按钮、弹窗遮罩等非报告元素。
   - 增加 `print-only`、`print-card`、`print-section` 打印辅助类。
   - 避免关键卡片和报告区块跨页断裂。

3. 管理端面试报告弹窗优化
   - “查看报告”弹窗接入专用 PDF 导出。
   - 增加打印专用报告头，包含平台标识、面试标题、候选人与面试时间。
   - 报告摘要、四维能力分、优势、待提升项和改进建议作为打印主体输出。

4. 候选人报告页优化
   - 候选人端报告页接入统一 PDF 导出函数。
   - 增加打印专用报告头和报告编号。
   - 打印时只输出报告内容，不输出候选人大厅导航与页面控制按钮。

5. 兼容旧报告路由
   - 保留的 `/admin/reports` 历史页面也接入同一套导出逻辑，避免历史链接导出效果不一致。

## 验证结果

- 已执行 `npm run build`。
- TypeScript 编译通过。
- Vite 生产构建通过。
- 已检查候选人报告页、管理端面试报告弹窗、旧管理端报告页均不再直接调用 `window.print()`。

## 后续建议

- 如果后续需要更强的企业交付能力，可以增加后端服务端 PDF 生成接口，保证不同浏览器下 PDF 版式完全一致。
