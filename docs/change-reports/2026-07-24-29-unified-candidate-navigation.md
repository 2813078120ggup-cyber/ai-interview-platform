# 候选人导航统一与能力报告优化

## 问题

- 候选人大厅、能力报告、题库与个人中心分别使用不同页面壳，导致侧边栏菜单数量、图标、文案和激活态表现不一致。
- 能力报告页面使用独立简化侧栏，只展示工作概览、AI 面试、能力报告三项菜单。
- 四维雷达图在大屏布局中的视觉占比偏大。

## 修复

- 所有候选人入口统一使用 CandidatePageShell。
- 统一展示工作概览、AI 面试、能力报告、题库与岗位、个人中心五项菜单。
- 统一菜单激活态为 Emerald 实色、白色文字与阴影，所有入口使用相同图标和文案。
- 将旧的 candidate/reports 地址重定向至 reports，确保能力报告菜单正确高亮。
- 缩小雷达图宽度，并加入轻量渐变容器；保留四维数值、网格、能力区域和数据点。

## 验证

- 前端生产构建：D:\nodejs\npm.cmd run build
