# 登录页 Hero 标题优化报告

## 本次目标

优化登录页左侧 Hero 区域的大标题和品牌区域，使其更整洁、更符合现代 AI SaaS 登录页视觉。

## 修改内容

1. 大标题文案优化
   - 原文案：“把每一次模拟面试，变成下一次的底气。”
   - 新文案：“每一次模拟面试，都成为下一次的底气。”
   - 避免 “面试” 被拆行，语义更顺、阅读更稳定。

2. 标题排版优化
   - 调整标题字号、最大宽度、行高和字距。
   - 控制标题在左侧区域中更自然地形成两行展示。
   - 增加 `text-wrap: balance`，改善不同宽度下的换行表现。

3. 品牌区优化
   - 放大品牌图标和品牌名视觉权重。
   - 调整副标题字号和间距，使顶部品牌信息更精致。

## 涉及文件

- `frontend-react/src/pages/login.tsx`
- `frontend-react/src/styles.css`

## 验证结果

已执行：

```bash
npm run build
```
