# 2026-07-25 前端体验与后台能力增强报告

## 变更目标

按照 P2「产品体验增强」与 P3「后台能力增强」优先级，先完成前端可用闭环；同时基于 `ui-ux-pro-max` 与 `design-taste-frontend` 的设计原则，将整体视觉从绿色后台感调整为更接近参考图的现代 AI 产品风格。

## 设计调整

- 主配色改为暖白背景、黑色主按钮、暖棕强调色、紫粉品牌点缀。
- 统一 Button、Badge、Card、左右侧 Shell 的圆角、阴影、动效与暗色模式 Token。
- 清理前端源码中残留的 `emerald`、`teal`、`green` 与旧绿色硬编码色值，重点统一按钮颜色。
- 候选人端与管理员端使用一致的产品化布局语言：固定侧栏、顶部工具区、卡片化内容、大留白。

## P2 产品体验增强

1. 面试中断恢复
   - 面试房保存当前题目序号与剩余时间。
   - 页面刷新或网络波动后，会恢复进行中的面试进度。

2. 自动保存回答草稿
   - 主观题文字回答按面试与题目维度保存到本地。
   - 提交答案或结束面试后自动清理草稿。

3. 报告导出 PDF
   - 候选人报告支持浏览器打印/导出 PDF。
   - 管理后台报告弹窗新增 PDF 导出按钮。

4. 候选人详情页
   - 管理员可查看候选人资料、统计概览、历史面试、能力趋势和报告入口。

## P3 后台能力增强

1. 题库批量导入
   - 管理端题库页新增 CSV/TSV 批量导入界面。
   - 支持下载模板、上传预览、批量提交题目。
   - Excel 文件提示先另存为 CSV，避免浏览器端引入过重解析依赖。

2. 面试模板
   - 创建面试时可选择 Java 后端、前端工程师、算法与编程、校园招聘通用模板。
   - 模板自动带入标题、面试类型、时长与题目数量。

3. 批量创建面试
   - 管理员可选择多个候选人，按模板和题库批量生成面试。
   - 支持设置间隔分钟，便于班级或企业批量安排。

4. 操作日志
   - 新增前端操作日志模块，记录创建面试、批量创建、创建题库、导入题目、创建候选人、状态调整等管理动作。
   - 操作日志支持搜索与 CSV 导出。
