# 2026-07-25 讯飞虚拟人 10163 调用修复

## 背景

面试房间中调用讯飞虚拟人失败，前端提示：

`讯飞虚拟人接口返回异常：400 / 10163`

该错误通常代表讯飞接口请求体字段未通过 schema 校验。

## 本次修改

- 调整讯飞虚拟人启动与控制请求结构，继续使用 `vms2d_start` / `vms2d_ctrl` 标准路径。
- 补充默认虚拟人形象 ID，避免后台未配置形象时发送空 `avatar_id`。
- 补充默认语音发音人，避免语音模型为空时控制指令不完整。
- 优化异常提示，接口失败时带出讯飞返回的 `message` / `desc` 等诊断信息，便于后续定位具体字段。

## 影响范围

- 候选人面试房间右侧 AI 面试官虚拟人区域。
- 管理后台系统设置中的讯飞虚拟人 Provider 配置。
- 浏览器语音朗读兜底逻辑保持不变，讯飞失败时仍会降级为本地数字人。

```bash
mvn -q -DskipTests package
```
