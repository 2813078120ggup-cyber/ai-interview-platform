# 2026-07-25 变更报告：统一浅色一页 PDF 导出

## 背景

管理端导出评测报告 PDF 时，会受到当前页面深色/浅色主题影响；同时直接打印后台弹窗时容易出现分页过多、模块被切割的问题。

## 本次修改

1. 管理端报告导出改为复用候选人端报告页面的导出流程。
   - 管理员点击“导出 PDF”时，会打开候选人报告路由并自动触发打印。
   - 避免打印后台弹窗、遮罩层和管理端布局。

2. 候选人报告页面支持 `?print=1` 自动打印。
   - 报告数据加载完成后自动进入打印流程。
   - 仍保留候选人端原有手动导出能力。

3. 打印模式强制锁定浅色主题。
   - 打印期间覆盖系统主题变量为浅色。
   - 不再受用户当前深色模式或浅色模式影响。

4. 优化 A4 单页打印布局。
   - 缩小字号、间距、圆角和图形尺寸。
   - 四项能力卡片改为打印时单行展示。
   - 报告主体使用更紧凑的双栏布局，降低分页和区域切割概率。

## 影响范围

- `frontend-react/src/components/report-detail-view.tsx`
- `frontend-react/src/pages/admin-interviews.tsx`
- `frontend-react/src/pages/candidate-report.tsx`
- `frontend-react/src/styles.css`

## 验证

- 已执行 `npm run build`
- TypeScript 编译通过
- Vite 生产构建通过

## 注意

浏览器打印预览最终分页仍会受纸张尺寸、缩放比例和浏览器打印设置影响。当前实现已在应用侧强制使用 A4、浅色主题和紧凑布局；建议打印预览中选择“纵向”和默认缩放。
