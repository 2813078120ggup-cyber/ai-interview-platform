# 管理端面试列表操作菜单化优化

## 调整时间

2026-07-25

## 背景

管理后台「面试管理」列表行内操作按钮较多，通知、回顾、通过、删除、查看报告同时展示时容易拥挤。此前虽已控制在单页内展示，但操作区信息密度仍偏高。

## 本次修改

- 将行内操作从五个按钮调整为三段式：
  - 回顾
  - 更多
  - 查看报告
- 将低频或危险操作收进「更多」菜单：
  - 发送通知
  - 标记通过
  - 删除面试
- 保留「查看报告」作为最后一个操作入口。
- 表格列宽重新分配，提升面试主题、报告状态和操作列的可读性。
- 保持所有操作文字横向展示，不再出现竖排文字。
- 菜单采用轻量浮层样式，和当前 Modern AI SaaS 视觉风格一致。
