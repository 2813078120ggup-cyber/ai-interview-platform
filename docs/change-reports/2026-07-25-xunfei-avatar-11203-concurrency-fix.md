# 讯飞虚拟人 11203 并发占用修复报告

## 问题

讯飞虚拟人调用失败，返回 `11203 / avatar authentication failed`。根据讯飞错误说明，该错误通常表示在线虚拟人驱动并发数超限、授权路数不足、订阅过期，或存在未释放的“持续中”交互链路。

## 修改内容

- 虚拟人 `start` 启动失败时立即关闭 WebSocket，避免失败连接继续残留。
- 讯飞返回非 0 错误码时主动关闭当前连接。
- 对 `11203` 增加明确诊断提示：并发路数占用、授权路数不足、订阅过期、需要在讯飞交互日志终止“持续中”链路。
- 修复虚拟人客户端中历史乱码提示，便于后续排障。
- 保留已实现的页面离开、结束面试、组件卸载时调用 `stop` 的释放逻辑。

## 仍需人工处理

代码只能释放本系统当前持有的会话。讯飞控制台中已经残留的历史“持续中”链路，需要在「交互平台」→「交互日志」中手动点击「终止对话」释放。

## 验证

已执行：

```bash
mvn -B -ntp -DskipTests package
```

结果：后端构建成功。
