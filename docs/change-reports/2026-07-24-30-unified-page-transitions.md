# 全局页面过渡动画统一

## 本次变更

- 提取 PageTransition 组件，统一使用工作概览同风格的淡入、轻微上移、淡出过渡。
- 候选人工作概览、AI 面试、能力报告、题库与岗位、个人中心使用统一页面壳中的单次过渡。
- 登录页、面试间、单份报告详情及管理端页面同步使用该过渡。
- 避免候选人页面壳与路由层同时包裹动画，防止出现重复或突兀的动画效果。

## 动画规范

- 进入：透明度 0 到 1，纵向位移 8px 到 0。
- 离开：透明度 1 到 0，纵向位移 0 到 -8px。
- 时长：0.18 秒，easeOut 缓动。

## 自测

- 前端生产构建：通过。
- 后端 Maven 测试：通过。
- 注意：测试日志中仍存在 UserRole、RolePermission 关联表未声明 MyBatis-Plus 主键的警告；该关联表不应调用 ById 系列方法，建议后续补充复合键映射或明确限制 Mapper 调用范围。
