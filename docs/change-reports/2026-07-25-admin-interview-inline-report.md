# 2026-07-25 管理后台报告入口收拢报告

## 变更目标

根据后台使用习惯，将“评测报告”从独立菜单入口收拢到“面试管理”上下文中。管理员不再需要先进入报告中心再查找对应面试，而是在面试列表中直接查看已生成报告。

## 主要变更

1. 面试管理列表新增报告状态列
   - 已生成报告：显示 `已生成 · 分数`。
   - 已结束但未生成报告：显示 `生成中`。
   - 未结束面试：提示 `面试结束后生成`。

2. 操作栏新增“查看报告”
   - 对于已结束且有报告的面试，操作栏显示“查看报告”按钮。
   - 点击后在面试管理页面内打开报告弹窗，不再跳转到独立报告页面。
   - 保留“回顾”按钮，用于查看面试过程与作答记录。

3. 报告弹窗
   - 展示综合得分、四维能力分、AI 总结、优势、待提升项与改进建议。
   - 支持导出 PDF。

4. 左侧菜单调整
   - 移除单独的“评测报告”菜单。
   - 管理后台核心入口保留为：工作台、面试管理、候选人、题库管理、操作日志。

## 验证结果

- 已执行 `npm run build`。
- TypeScript 编译通过。
- Vite 生产构建通过。

## 注意事项

- `/admin/reports` 路由暂时保留，避免历史链接或候选人详情中的旧入口失效。
- 本次只修改前端与变更报告，不提交本地后端配置文件。
